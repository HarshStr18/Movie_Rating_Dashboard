# 🎬 AI-Powered Movie Rating Analysis Dashboard

## 📌 About the Project

The **Movie Rating Analysis Dashboard** is a Python-based data analysis project designed to analyze movie ratings, viewer preferences, and entertainment trends. It transforms movie rating datasets into meaningful insights through interactive visualizations and statistical analysis.

The project helps users understand movie popularity, rating distributions, genre preferences, and audience behavior using data analytics.

## 🚀 Features

- **Movie Search:** Search for movies by their titles.
- **Rating Analysis:** Analyze average ratings and rating distributions.
- **Popularity Analysis:** Identify popular movies based on viewer ratings and rating counts.
- **Genre Analysis:** Explore audience preferences across different movie genres.
- **Interactive Dashboard:** View movie insights through interactive charts and visualizations.
- **Statistical Insights:** Analyze rating patterns, average ratings, and rating variations.
- **Movie Details:** Explore movie titles, release years, genres, and rating information.
- **Dark Theme:** Clean and user-friendly dark interface.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical computations.
- **Streamlit** – Interactive dashboard development.
- **Plotly** – Data visualization.
- **CSV Dataset** – Movie information and user ratings.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/HarshStr18/AI-Movie-Rating-Analysis.git
```

### 2. Navigate to the Project Folder

```bash
cd AI-Movie-Rating-Analysis
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

The dashboard will open in your browser.
